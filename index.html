Introduction

Throughout my Computer Science program at Southern New Hampshire University, I have developed skills in programming, software design, security, data structures, databases, testing, and problem solving. This ePortfolio brings together examples of my coursework and capstone enhancements to show how I apply these skills to practical software development.

The projects represented here demonstrate more than the ability to write code. They also show my ability to examine existing software, identify areas for improvement, implement changes, and explain the reasoning behind my decisions.

Software Engineering and Design

My software engineering work includes enhancements to my CS 360 mobile event-tracking application. This work focuses on improving usability, validating user input, and making the application easier to maintain. Reviewing and improving an existing application helped me consider how interface design, organization, and validation contribute to a reliable user experience.

These enhancements demonstrate my ability to evaluate an existing software solution, identify practical improvements, and apply software development principles to make the application more usable and maintainable.

Algorithms and Data Structures

My CS 300 Course Planner project demonstrates my experience organizing and processing course information in C++. My enhancement work includes a Binary Search Tree and in-order traversal, which provide a structured way to store and retrieve course information in sorted order.

This project strengthened my understanding of how data structures affect the organization and retrieval of information. It also demonstrates my ability to implement algorithmic concepts in a practical program and explain how those concepts support the program's functionality.

Databases

My database artifact focuses on data management in the CS 360 mobile event-tracking application. The enhancements described in my portfolio include event searching, filtering, sorting, and indexing. These features demonstrate how organizing and accessing stored information can support the needs of an application and its users.

This work connects database concepts with application functionality and demonstrates my ability to consider how information is stored, organized, and retrieved.

Technical Skills and Professional Growth

Throughout the Computer Science program, I have strengthened my ability to analyze programming problems, develop solutions, debug code, test functionality, and improve existing software. I have also learned to consider security, maintainability, data organization, and usability when evaluating computing solutions.

The artifacts in this ePortfolio provide examples of these skills in practice. Together, they demonstrate my experience with software development, data structures and algorithms, and database functionality, as well as my ability to apply feedback and refine a project through enhancement work.

Course Outcomes

My capstone enhancements demonstrate my ability to design and evaluate computing solutions, apply algorithmic principles, and use appropriate computing techniques and tools to implement improvements. The projects also provide examples of analyzing existing systems, making targeted changes, and communicating the purpose and impact of those changes.

Career Goals

My career goal is to pursue a career in software development. I want to continue building my skills by developing secure, efficient, reliable, and maintainable applications.

This ePortfolio represents my growth as a computer science student and provides examples of how I can apply the knowledge and skills I developed throughout my degree to practical software development projects.
