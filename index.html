Introduction

Throughout my Computer Science program at Southern New Hampshire University, I have developed skills in programming, software development, databases, algorithms, testing, security, and problem-solving. When I started the program, I focused mainly on writing code and getting programs to work correctly. As I progressed through my courses, I learned that successful software development involves much more than making a program run. Software also needs to be organized, maintainable, secure, reliable, and designed around the needs of its users.

My coursework has helped me become more comfortable analyzing problems, breaking them into smaller tasks, debugging errors, and choosing appropriate solutions. I have also learned the importance of documenting my work and explaining technical decisions so that other people can understand them. These skills are important because software developers often work with other developers, users, and stakeholders who have different levels of technical knowledge.

My CS 499 ePortfolio brings together work from my Computer Science program and demonstrates how I have developed as a programmer and problem-solver. The artifacts in my portfolio include my CS 300 Course Planner and my CS 360 mobile event-tracking application. Reviewing these projects has given me an opportunity to reflect on the skills I have developed, identify areas for improvement, and consider how I can apply what I have learned to future software development work.

Software Engineering and Design

Software engineering and design have taught me to consider how a program is organized and how users interact with it, rather than focusing only on whether the code works. Good design includes readable code, clear navigation, appropriate input validation, and a structure that makes future changes easier. These practices help make software easier to maintain and reduce the likelihood of errors.

My CS 360 mobile event-tracking application is an example of how software engineering concepts can be applied to a practical project. The application involves managing event information and providing users with a way to work with that information. Reviewing this project helped me recognize the importance of organizing the application, making its features understandable, and considering the experience of the person using it.

In my portfolio, I focus on the design and implementation decisions that support the application's purpose. I also recognize the value of input validation, a consistent interface, and clear separation of responsibilities when developing software. These are areas I can continue to improve as I work toward writing more maintainable and professional code.

Algorithms and Data Structures

My coursework in algorithms and data structures helped me understand that the way information is organized can affect how efficiently a program operates. Choosing a suitable data structure depends on the problem being solved, the operations a program needs to perform, and the trade-offs involved in different approaches.

My CS 300 Course Planner is an example of these concepts in practice. The project was developed in C++ and used a binary search tree to organize course information. It also used in-order traversal to display course information in sorted order. Working with this project helped me understand how a data structure can support a program's requirements and how traversal methods affect the way information is retrieved and presented.

This experience improved my ability to think through a problem before choosing an implementation. Instead of selecting an approach simply because it works, I learned to consider whether it is appropriate for the information being managed and the expected behavior of the program. These skills are useful when developing applications that need to process, organize, and retrieve information effectively.

Databases and Information Management

Database coursework helped me understand the importance of storing, organizing, and retrieving information accurately. Applications often depend on reliable data, so developers need to consider how information is structured, how it is accessed, and how changes are handled. Poor data management can lead to incorrect results, duplicated information, and problems for users.

My work with the CS 360 mobile event-tracking application gave me an opportunity to consider how application data supports the features a user expects. Event information must be managed in a way that allows the application to provide useful and consistent results. This helped me recognize the relationship between an application's interface, its underlying logic, and the data it uses.

Through my studies, I have also learned that data management involves more than storing information. Developers must consider data accuracy, organization, access, and protection. These considerations are important when building applications that people rely on to manage information.

Technical Skills and Professional Growth

My Computer Science program has helped me build experience with programming languages, software development tools, debugging, testing, and problem-solving. Working on different projects has shown me that each problem can require a different approach. Sometimes the solution involves improving an algorithm, while other times it involves reorganizing code, validating input, or reconsidering how a feature should work.

I have also learned the importance of being able to explain technical work clearly. Code needs to be understandable to the people who maintain it, and project decisions need to make sense to the people affected by them. Documentation, communication, and collaboration are therefore important parts of professional software development.

My security coursework, including CS 305, introduced me to the importance of secure communications and protecting information. It helped me understand that security should be considered throughout development rather than treated as an afterthought. I want to continue strengthening these skills as I gain more experience and work on more complex projects.

Computer Science Program Course Outcomes

The five course outcomes below represent important skills developed throughout my Computer Science program. My coursework and ePortfolio artifacts provide examples of how I have practiced these skills and how I plan to apply them in professional software development. Together, the outcomes cover collaboration, communication, algorithmic problem-solving, software development, and security.

Outcome 1: Collaboration and Decision-Making

Employ strategies for building collaborative environments that enable diverse audiences to support organizational decision-making in the field of computer science.

This outcome emphasizes the importance of working with others, considering different perspectives, and sharing technical information in a way that supports informed decisions. Software development often involves people with different responsibilities and levels of technical knowledge. Developers need to listen to feedback, explain their reasoning, and consider how their decisions affect users and the larger project.

My coursework has helped me recognize that solving a programming problem is not always an individual task. Developers may need to discuss requirements, explain possible approaches, and evaluate trade-offs before choosing a solution. My CS 300 Course Planner and CS 360 mobile event-tracking application also demonstrate the importance of considering the purpose of a program and the people who will use or maintain it.

As I continue developing my professional skills, I want to build on this foundation by communicating openly, considering feedback, and making technical decisions based on project requirements and user needs. These practices can help me contribute to a collaborative development environment and support better decisions within a team.

Outcome 2: Professional Communication

Design, develop, and deliver professional-quality oral, written, and visual communications that are coherent, technically sound, and appropriately adapted to specific audiences and contexts.

This outcome focuses on communicating technical information clearly and professionally. Computer scientists need to explain their work through written documentation, presentations, diagrams, code comments, and discussions. The information should be accurate and organized while matching the knowledge and needs of the intended audience.

Developing this ePortfolio has given me an opportunity to organize my work and explain the purpose of my projects, the concepts they demonstrate, and the skills I have gained. For example, I can describe how my CS 300 Course Planner uses a binary search tree and in-order traversal without relying only on the source code to communicate its purpose. I can also explain the role of the CS 360 application and the importance of its organization and data management.

I have learned that technical communication should help another person understand not only what a program does, but also how it works and why certain decisions were made. Going forward, I will apply these skills when documenting code, explaining solutions, communicating with teammates, and presenting my work to technical and nontechnical audiences.

Outcome 3: Algorithms, Data Structures, and Problem-Solving

Design and evaluate computing solutions that solve a given problem using algorithmic principles and computer science practices and standards appropriate to its solution while managing the trade-offs involved in design choices.

This outcome emphasizes selecting appropriate algorithms and data structures, evaluating possible solutions, and understanding the trade-offs involved in implementation decisions. A solution should meet the requirements of the problem while taking into account factors such as efficiency, organization, readability, and maintainability.

My CS 300 Course Planner demonstrates this outcome through its use of C++ and a binary search tree to organize course information. The project uses in-order traversal to present information in sorted order. Completing this work helped me understand how a data structure supports specific program requirements and how the choice of structure influences the way information is processed.

This experience also taught me to consider why one approach may be more appropriate than another. Different solutions can produce the same result but vary in complexity, efficiency, and ease of maintenance. I can apply this understanding to future programming tasks by analyzing requirements, comparing possible approaches, testing my solutions, and selecting implementations that are appropriate for the problem.

Outcome 4: Software Development and Computing Practices

Demonstrate an ability to use well-founded and innovative techniques, skills, and tools in computing practices for the purpose of implementing computer solutions that deliver value and accomplish industry-specific goals.

This outcome focuses on applying programming knowledge, development tools, and professional practices to create solutions that serve a clear purpose. Building useful software requires more than writing code. Developers must understand requirements, organize their work, test functionality, and consider how the completed application will meet the needs of its users.

My CS 360 mobile event-tracking application is an example of applying software development concepts to a practical user need. The application manages event information, connecting its features to the information users need to work with. Reviewing this project has helped me recognize the importance of application organization, usability, input validation, and maintainability when developing software.

My CS 300 Course Planner provides another example of applying programming skills and data structures to solve a defined problem. Together, these projects demonstrate different aspects of computing, from organizing information to developing application functionality. I plan to continue building on these experiences by using appropriate development tools, following coding standards, testing my work, and considering how my solutions provide value to users.

Outcome 5: Security and Protection of Data

Develop a security mindset that anticipates adversarial exploits in software architecture and designs to expose potential vulnerabilities, mitigate design flaws, and ensure privacy and enhanced security of data and resources.

This outcome emphasizes the importance of considering security throughout the software development process. Developers need to think about how an application could be misused, what vulnerabilities could expose information, and how design and implementation decisions can reduce those risks. Security is not something that should be considered only after an application has been completed.

My CS 305 secure communications coursework helped me develop a better understanding of protecting information and the importance of secure communication practices. This work reinforced the need to consider how information is transmitted and protected, as well as how security decisions affect the reliability and trustworthiness of a system.

I can apply this security mindset to projects such as my CS 360 mobile event-tracking application by considering how application data is accessed, how user input is handled, and what could happen if information were exposed or improperly modified. These are important considerations when evaluating an application's design, even when a particular security enhancement has not been implemented.

Moving forward, I want to continue learning how to identify vulnerabilities, evaluate potential risks, validate input, protect sensitive information, and follow secure coding practices. Developing these habits will help me create software that is not only functional, but also more reliable and responsible in how it handles data and resources.

Overall, these five outcomes reflect the different skills I have developed during my Computer Science program. Collaboration and communication help me explain ideas and work with others, while algorithms and software engineering help me develop practical solutions. Security adds another important responsibility by reminding me to consider vulnerabilities and protect information. My ePortfolio brings these areas together and gives me a foundation to continue improving as a software developer.
