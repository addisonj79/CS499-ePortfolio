# CS 360 Database Artifact

## Overview

This folder contains my database artifact for the CS 499 Computer Science Capstone at Southern New Hampshire University. The artifact is based on my Mobile Event-Tracking Application developed for CS 360.

The application manages event information and provides functionality for users to create, view, edit, and manage events.

## Purpose

The purpose of this artifact is to demonstrate my understanding of database development and data management within an application. The project provides an example of how application data can be stored, organized, and accessed to support the application's functionality.

## Database Functionality

The database-related aspects of this project focus on managing event information and supporting the application's event-management features.

These features provide a foundation for examining how data is stored, retrieved, and organized within a mobile application.

## Capstone Enhancement

As part of my CS 499 capstone, this artifact supports my work in the Databases category. My enhancement work focuses on evaluating the existing data-management approach and identifying opportunities to improve how event information is organized, searched, filtered, and sorted.
