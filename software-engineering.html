Software Engineering Enhancement

My software engineering enhancement builds on the existing mobile event-tracking application. The objective is to improve the application's usability, reliability, and maintainability while preserving its core functionality.

Areas of Focus

  • Improve the user interface and navigation to make the application easier to use.
  • Strengthen input validation to help prevent invalid event information from being entered.
  • Improve the workflow for creating, viewing, editing, and deleting events.
  • Organize the code to make the application easier to understand and maintain.
  • Preserve existing functionality while improving the overall application experience.

Reflection

Working on the mobile event-tracking application helped me understand the importance of software design, usability, and maintainability. An application needs to do more than provide the required features; it should also be organized in a way that makes it understandable and easier to improve.

Reviewing and enhancing this project allowed me to evaluate existing functionality and consider how improvements to navigation, validation, and code organization could benefit users and future developers.

These experiences have strengthened my ability to analyze existing software, identify areas for improvement, and apply software engineering principles to practical development projects.
