Overview

This section of my ePortfolio demonstrates my knowledge of database design, data management, and the use of data to support application functionality. Through my work on the Mobile Event-Tracking Application, I developed an understanding of how information can be organized, stored, retrieved, and managed to meet user needs.

My database enhancement focuses on improving the way users organize and locate event information. This work demonstrates my ability to evaluate an existing application, identify opportunities for improvement, and apply database concepts to create a more useful and maintainable software solution.

Original Artifact

The original artifact is my Mobile Event-Tracking Application from CS 360. The application allows users to manage event information and provides a foundation for demonstrating database operations within a software application.

Reviewing the original implementation helped me identify opportunities to improve event organization, data retrieval, and the overall experience of working with stored information.

Code Review

During my code review, I examined how the application manages event data and how its existing implementation could be improved. I considered the organization of the code, the handling of stored information, and opportunities to make retrieving and managing events more efficient and convenient.

This review helped establish a starting point for my database enhancement and allowed me to identify areas where changes could improve the application's functionality and maintainability.

Database Enhancement

The goal of my database enhancement is to improve how users search for, organize, and access event information. By building on the existing application, I can demonstrate how database-related improvements can make an application easier to use without losing its original purpose.

Enhancement Goals

  • Improve the organization and retrieval of event records.
  • Support more convenient searching and filtering of events.
  • Improve sorting options so users can organize event information according to their needs.
  • Maintain reliable data handling as the application evolves.
  • Keep the code organized and maintainable.

These improvements demonstrate how database concepts can be applied to an existing software project to support practical user requirements.

Reflection

Working on this artifact has helped me better understand the relationship between databases and application development. Storing information is only one part of building an effective application. Users must also be able to retrieve and organize that information in a way that meets their needs.

The enhancement process has encouraged me to think critically about the original design, evaluate potential improvements, and consider how changes affect the overall application. These skills will be valuable in future software development projects where reliable data management and maintainable code are important.

Overall, this project demonstrates my continued growth in database concepts, application development, and technical problem solving.
