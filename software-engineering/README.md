# Original CS 360 Mobile Event-Tracking Application

## Overview

This project is my original Mobile Event-Tracking Application developed for CS 360 at Southern New Hampshire University. The application focuses on helping users create, view, edit, and manage event information through a mobile interface.

## Purpose

The purpose of this project was to develop a mobile application that provides users with a way to organize and manage events. This artifact represents my original work before the enhancements completed for my CS 499 Computer Science Capstone.

## Functionality

The application was designed around event management, including:

- Creating events.
- Viewing saved event information.
- Editing existing events.
- Managing event records.

## Software Engineering and Design

This artifact demonstrates my experience with mobile application development, software organization, user interface design, and application functionality. It provides a foundation for evaluating the existing implementation and identifying opportunities for improvement.

## Capstone Connection

For my CS 499 capstone, I used this original project as the basis for my Software Engineering and Design enhancement. The enhancement work focuses on evaluating the original application and improving its usability, input validation, event-management workflows, and code organization.
