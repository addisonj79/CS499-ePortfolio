Enhancement Narrative

The artifact I chose is my Course Planner program that I originally made for my CS 300 class. I created it in C++, and the program lets the user load course information from a file, view a list of courses, and look up a specific course and its prerequisites.

I chose this project because I think it shows some of the skills I learned with algorithms and data structures. In the original project, I used a vector to store the courses and a linear search to find a course. For my enhancement, I added a Binary Search Tree to store the courses and added functions to insert and search for courses in the tree. I also added an in-order traversal so the courses can be printed in order.

I believe I met the course outcomes I planned to work on because I improved the original program and applied a different data structure and algorithms. I do not have any major changes to my outcome plans.

While working on the enhancement, I learned more about how Binary Search Trees work and how recursion is used when inserting and searching for information. One of the harder parts was adding the tree without breaking parts of the program that were already working. I also had to make sure the courses were being placed in the correct positions in the tree and that the search would find the correct course.

Overall, this project helped me better understand pointers, recursion, and data structures.
