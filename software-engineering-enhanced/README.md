# Enhanced CS 360 Mobile Event-Tracking Application

## Overview

This folder contains the enhanced artifact for my CS 499 Computer Science Capstone at Southern New Hampshire University. The project is based on my original CS 360 Mobile Event-Tracking Application, which allows users to create, view, edit, and manage events.

## Purpose

The purpose of this enhancement is to demonstrate my software engineering and design skills by reviewing and improving an existing application. The project focuses on application functionality, user experience, input validation, and code organization.

## Enhancement Goals

The enhancement work focuses on the following areas:

- Improving application usability and navigation.
- Strengthening input validation.
- Improving event creation, viewing, editing, and deletion workflows.
- Improving code organization, readability, and maintainability.
- Preserving the application's core functionality.
